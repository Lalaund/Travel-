# Our Little World Tour

Ein digitales Reisetagebuch mit einer antiken Buch-Optik und 20 außergewöhnlichen Reisezielen.

## Kostenlos veröffentlichen mit GitHub Pages

1. Melde dich kostenlos bei https://github.com an.
2. Erstelle ein neues Repository, zum Beispiel `our-little-world-tour`.
3. Wähle **Public** und erstelle das Repository.
4. Lade `index.html` aus diesem Projektordner hoch:
   - Im Repository auf **Add file** → **Upload files** klicken.
   - `index.html` auswählen und den Upload mit **Commit changes** bestätigen.
5. Öffne im Repository **Settings** → **Pages**.
6. Unter **Build and deployment** bei **Source** `Deploy from a branch` wählen.
7. Als Branch `main` und Ordner `/(root)` auswählen, dann **Save**.
8. Nach kurzer Zeit zeigt GitHub Pages dort deine kostenlose Website-Adresse an.

## Hinweise

- Die Website ist eine statische HTML-Seite. Es sind kein Server, keine Datenbank und kein kostenpflichtiges Hosting nötig.
- Die Schriftarten und die Reisebilder werden von externen Diensten geladen. Daher benötigt die Website beim Aufrufen eine Internetverbindung.
- Die Bilder sind illustrative Reisebilder und nicht in jedem Fall Originalaufnahmen exakt des genannten Ortes.
- Du kannst die Website lokal testen, indem du `index.html` im Browser öffnest.
